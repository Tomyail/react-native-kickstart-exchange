# iOS implementation

`KickstartExchangeBridge` is an Expo Modules API pod with an iOS 18.0 deployment target.

- `KickstartExchangeModule.swift` registers the `KickstartExchange` native view and hosts SwiftUI in `UIHostingController`.
- `KickstartExchangeResourceBundle.swift` provides the `Bundle.module` contract normally generated by SwiftPM.
- `Vendor/KickstartSDK/` contains the MIT-licensed upstream source at tag `0.5.0`, its resources, privacy manifest, and license.
- `KickstartExchangeBridge.podspec` compiles both bridge and vendor sources into one CocoaPods target.

No application-target Swift Package linking is required.
